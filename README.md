# 领导会议日程（脱敏公开版）

> 把一段会议通知原文，变成一张排得清清楚楚的领导周历。
>
> 单文件 Web 应用 + 本地桥接服务，零依赖、本地解析、数据不出本机。

## 这是什么

办公室每天要处理的事：**收会议通知 → 判断该谁去 → 排进日程 → 填进共享表格 → 临时有人请假再改一遍**。

这个工具把中间全部自动化：

```
通知原文  ──▶  自动拆出 日期 / 时间 / 地点 / 会议名 / 参会领导
          ──▶  按分工判断该谁去（含 AB 角备选）
          ──▶  排进周视图日历，撞车自动标红
          ──▶  一键写进云文档对应格子
```

**零依赖、免安装、打开即用**。核心逻辑压缩在单个 `index.html` 里，双击即可运行。

> ⚠️ **本仓库是「脱敏公开版」**：所有真实人名、单位名、会议记录、口令均已隔离，代码中仅保留虚拟示例数据。真实数据只存在于内部分发环境，绝不进入 Git。

## 快速开始

### 直接使用（无需安装）

1. 打开 `会议日程应用/index.html`，双击即可在浏览器里运行。
2. 粘贴一段会议通知原文，自动解析出日期、时间、地点、会议名、参会领导。
3. 需要多台电脑共享时，运行本地桥接服务（见下）。

### 启动本地桥接服务（可选）

桥接服务提供云文档同步、文件监听、跨设备状态共享等能力：

```bash
cd 会议日程应用
node bridge/server.mjs   # 监听 127.0.0.1:7788
```

Windows 下也可直接双击 `会议日程应用/启动同步服务.bat`。

## 核心能力

| 能力 | 说明 |
|------|------|
| 粘贴即解析 | 识别十几种日期写法，拆出日期/时间/地点/会议名/参会领导 |
| 周视图日历 | 三色区分会议层级，卡片直接写时间+会议名+参会领导 |
| 冲突检测 | 同一领导同天多场会，间隔 < 90 分钟自动标红 |
| 参会推荐 | 内置领导分工与 AB 角，自动建议主参会人+备选+理由 |
| 云文档同步 | 按日期找行、按领导找列，追加不覆盖、去重不写错格 |
| 参会统计 | 周/月口径统计 + 外出培训登记 |
| 文件监听 | 监听文件夹自动发现新通知，本地解析后询问导入 |

详细功能说明见 [会议日程应用/README.md](会议日程应用/README.md) 与 [会议日程应用/使用说明.md](会议日程应用/使用说明.md)。

## 脱敏纪律（安全红线）

本仓库是单位的**内部办公工具**公开版，单位数据必须与代码隔离：

- **绝不**将真实人名、单位名、会议室号、公文文号、密钥令牌、真实会议内容放进任何被跟踪的文件。
- 代码中的示例一律使用**脱敏占位符**（如 `[某领导]`、`[某单位]`、`[X楼会议室]`）。
- 真实数据文件通过 `.gitignore` 排除（见 `AGENTS.md` 第 4 节）。

提交钩子会在每次 `git commit` 前自动扫描敏感词与密钥，命中即拦截。详细规范见 [AGENTS.md](AGENTS.md)。

## 参与开发

本仓库遵循「交付纪律」（见 `AGENTS.md`）：

- 提交消息格式：`<gitmoji> 任务号: 简短描述`（如 `✨ TASK-214: 新增会议导入解析`）
- 分支规范：`feature/任务号-描述`、`bugfix/任务号-描述` 等
- 安装提交钩子：

```bash
git config core.hooksPath .githooks
```

## 技术栈

- **前端**：原生 HTML/CSS/JS，单文件 `index.html`，无框架、无构建、无第三方依赖
- **后端**：Node.js 本地桥接服务（`bridge/`），仅监听 127.0.0.1
- **解析**：Word(.docx)/PDF 纯前端/纯 Node 解析，图片 OCR 走本机 Python
- **测试**：20 个 Node 测试套件，覆盖解析、冲突、统计、同步、监听等
