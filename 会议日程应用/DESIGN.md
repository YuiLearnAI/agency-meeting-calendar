# DESIGN.md · 领导会议日程

> 视觉基线：`awesome-design-md/design-md/airbnb/DESIGN.md`（Airbnb）。
> 本项目是「Operate」型工具界面（日历 + 录入 + 统计），因此保留 Airbnb 的
> 白底、发丝线、柔软圆角、单层阴影与单一品牌红，但排版克制、密度偏高，
> 不照搬营销页的大留白与摄影主导。

---

## 1. 设计原则

1. **白底优先**：默认浅色主题（`data-theme="light"`）。页面 90% 是白 + 墨色文字，红色只在关键动作上出现。
2. **单一品牌色**：Rausch 红只承担「主操作、今日高亮、关键计数、可点击强调」四类语义。
3. **发丝线分隔**：用 1px 边框划分区域与卡片，不靠大色块与投影堆叠层级。
4. **单层阴影**：全站只有一档悬浮阴影，且只出现在悬浮/浮层上；平铺卡片无阴影。
5. **无发光、无渐变、无侧边色条**：不使用彩色投影、渐变背景、`border-left` 粗色条。

---

## 2. 颜色令牌

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#ffffff` | `#141414` | 页面画布 |
| `--panel` | `#ffffff` | `#1c1c1c` | 卡片/面板表面 |
| `--panel-2` | `#f7f7f7` | `#242424` | 次级表面（输入框、表头） |
| `--panel-3` | `#f2f2f2` | `#2e2e2e` | 悬停/选中底色 |
| `--line` | `#dddddd` | `#3a3a3a` | 发丝线（默认边框） |
| `--line-soft` | `#ebebeb` | `#2c2c2c` | 更浅的分隔线 |
| `--txt` | `#222222` | `#f2f2f2` | 主文字（近黑，不用纯黑） |
| `--dim` | `#6a6a6a` | `#a8a8a8` | 次级文字 |
| `--dim-2` | `#767676` | `#8a8a8a` | 弱化文字（仍满足 AA） |
| `--brand` | `#ff385c` | `#ff385c` | 装饰性品牌红（圆点、角标、进度条），**不承载文字** |
| `--accent` | `#d5003c` | `#ff385c` | 可交互红：链接、图标、强调文字 |
| `--accent-fill` | `#d5003c` | `#e00b41` | 实心按钮底色（配白字，≥4.5:1） |
| `--accent-ink` | `#ffffff` | `#ffffff` | 红底上的文字 |
| `--danger` | `#c13515` | `#ff6b6f` | 错误/删除 |
| `--warn` | `#b87700` | `#f0a020` | 冲突/提醒 |

**为什么 `--accent` 不是 `#ff385c`**：`#ff385c` 与白字对比度仅 3.5:1，与白底文字对比度同样不足 4.5:1。
`#d5003c`（浅色）与 `#e00b41`（深色实心底）是 Rausch 的加深变体，保持品牌观感的同时通过 WCAG AA。
`--brand` 保留原色，仅用于圆点/角标等非文字装饰。

### 会议分类（浅色底 + 同色系发丝线，替代原渐变块）

| 分类 | 背景 | 边框 | 时间文字 |
|---|---|---|---|
| 市政府 / 市级（city） | `#fff0f3` | `#ffd1da` | `#b32505` |
| 局内部（internal） | `#eefaf1` | `#c9ecd4` | `#006607` |
| 市直部门（dept） | `#f7f7f7` | `#dddddd` | `#6a6a6a` |

深色主题用同色系低透明度填充（`rgba(255,56,92,.14)` 等）。

## 3. 字体

```css
--font: "Airbnb Cereal VF", -apple-system, "Segoe UI", Roboto, "Helvetica Neue",
        "PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif;
```

- Airbnb Cereal 不随包分发（无网络、无授权），实际落到系统字体；中文优先 PingFang / 微软雅黑。
- **字号下限 12px**：正文 14px，辅助信息 12–13px，不使用小于 12px 的字（原实现有 9.5–11.5px，已全部抬到 12px）。
- 层级：页面标题 16px/700；区块标题 13px/700；正文 14px/400；辅助 12px/400。
- 字重克制：只用 400 / 500 / 600 / 700，不堆 800+。

## 4. 圆角与间距

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 8px | 按钮、输入框、会议卡片、列表项 |
| `--radius` | 14px | 日历列、浮层、统计卡 |
| — | 16px | 弹窗 |
| — | 9999px | 搜索框、胶囊标签、计数徽标 |

基础间距 4px 步进；区块内边距 12–16px；卡片间距 9–12px（工具界面密度高于营销页）。

---

## 5. 阴影（只有一档）

```css
--shadow:       0 6px 16px rgba(0,0,0,.12), 0 0 0 1px rgba(0,0,0,.04);
--shadow-hover: 0 8px 22px rgba(0,0,0,.14), 0 0 0 1px rgba(0,0,0,.05);
```

- 平铺卡片：无阴影，仅 1px 发丝线。
- 悬浮/浮层（弹窗、下拉、统计卡、监听卡）：`--shadow`。
- 卡片悬停：`--shadow-hover`。
- **禁止**：彩色投影、零偏移彩色光环、渐变边框。

---

## 6. 组件规范

- **按钮**：8px 圆角，`padding 8px 14px`，字重 500；主按钮用 `--accent-fill` + 白字；悬停换深一档红，不用 `filter: brightness()`。
- **输入框**：8px 圆角，`--panel-2` 底，1px 发丝线；聚焦时边框转墨色并内描 1px，**不做外发光环**。
- **胶囊/徽标**：9999px 圆角；计数徽标用 `--accent-fill` 白字。
- **会议卡片**：8px 圆角，分类浅底 + 同色系 1px 边框；悬停轻微上浮 + 单层阴影。
- **日历列**：14px 圆角，白底 + 发丝线；今日列用 `--accent` 1px 内描边（不是外发光）。
- **浮层/弹窗**：14–16px 圆角 + `--shadow`；遮罩 `rgba(0,0,0,.5)`。

---

## 7. 无障碍

- 正文对比度 ≥ 4.5:1；大字（≥24px 或 ≥18.66px 粗体）≥ 3:1。
- 可点击目标高度 ≥ 32px，主操作 ≥ 40px。
- 焦点态必须可见（墨色边框），不能只靠颜色变化。

---

## 8. 检测基线

使用 `impeccable` 检测器（`.design-tools/impeccable`）作为回归门：

```bash
npx impeccable detect index.html 使用说明.html README.html \
  "分发版/领导会议日程.html" "分发版/使用说明.html"
```

要求：**0 anti-patterns**。已清理的问题类型：低对比文字、<12px 小字、彩色发光阴影、侧边粗色条、破折号过密。
