## 一、这是什么

一个跑在**本机**的会议日程网页应用，把「会议通知原文」自动解析成结构化条目，落到**周视图日历**上，并**自动同步到金山文档《会议安排.xlsx》**。

核心能力：

- **智能解析**：粘贴会议通知原文，自动抽出日期、时间、地点、会议名称、参会领导、备注
- **周视图日历**：按领导分列，一眼看清一周谁哪天有会、是否有时间冲突
- **自动推荐参会领导**：根据领导班子分工，给出主参会人 + AB 角备选
- **双向同步**：日历上改完自动写云文档；云文档被人改了自动读回
- **参会统计**：按周/月统计每位领导参会场次，一键复制名单

**数据安全**：应用运行在本机，服务监听 `0.0.0.0:7788`——本机访问 `127.0.0.1:7788`，**同一局域网**内其他电脑访问 `http://192.168.1.100:7788`（需输入访问口令）。服务**不暴露到公网**（受单位路由器 NAT 隔离，外网不可达）；会议数据只有一条出站链路——本机授权的金山文档。没有任何第三方中转。

## 二、快速上手（3 步）

**第 1 步：开机即用，无需手动启动。**

本应用已配置为**开机自启**。电脑开机登录后约 15 秒，同步服务自动在后台运行。

**第 2 步：打开浏览器，访问这个地址：**

```
http://127.0.0.1:7788/
```

建议收藏到书签。

**第 3 步：确认右上角是「● 实时同步中」。**

- 绿点「● 实时同步中」＝ 已连上金山文档，一切正常
- 黄点 ＝ 服务在线但尚未授权，点它 → 在弹出的页面点「同意」即可

登录只需一次，凭证保存在本机，之后重启电脑也不用再登录。

## 三、局域网其他电脑访问

单位内网（同一个路由器/交换机下）的其他电脑，也能访问这台电脑上的应用，实现多人共用同一套会议日程和云文档。

### 访问方法

其他电脑打开浏览器，访问：

```
http://192.168.1.100:7788/
```

首次打开会先显示「**访问验证**」页，输入访问口令后即可进入。口令正确后，浏览器会自动记住（30 天免再次输入）。

### 访问口令

- 当前口令：**口令见本机 .access-key.txt**
- 口令存放在本机 `会议日程应用\bridge\.access-key.txt`，修改该文件内容即可更换口令，**改完需重启服务**（双击「恢复自启动.bat」）
- 口令只作为「内网访问门」，防止无关人员随意打开。它不是加密，不能替代对会议内容的内部保密管理

### 重要前提（先想清楚）

| 前提 | 说明 |
|---|---|
| 主机要常开 | 其他电脑访问时，**这台电脑必须开机**且同步服务在线。你下班关机，别人就用不了 |
| IP 要固定 | 当前 IP 是 `192.168.1.100`（动态分配）。若路由器重新分配 IP，地址会变，需重新告知同事新地址。**建议在路由器里给这台电脑绑定固定 IP** |
| 谁都能改云文档 | 拿到口令的内网用户，都能通过这个服务读写金山文档（凭证在本机）。口令务必只给需要的人 |

### 本机与局域网的区别

| | 本机 | 局域网其他电脑 |
|---|---|---|
| 地址 | `http://127.0.0.1:7788/` | `http://192.168.1.100:7788/` |
| 口令 | 本机访问也需口令 | 需口令 |
| 外网 | 均不可达（受单位路由器隔离，不暴露公网） |

## 四、日常使用步骤

### 录入一场会议（最常用）

1. 复制会议通知文字（微信、OA、Word 都行）
2. 粘贴进左侧「粘贴会议文本」输入框
3. 点 **「解析并预览」**
4. 在预览卡片里**核对**日期、时间、地点、参会领导是否正确（不对就当场改）
5. 点 **「导入到日历」**

导入后约 1.5 秒，自动写进云文档。不用再点任何同步按钮。

### 支持两种文本格式

**① 会议通知原文**（推荐，直接粘）：

```
10月26日（星期一）上午9:00，在B027会议室召开局党组会议，请谷六副局长参加。
```

**② 一行一条**（简写）：

```
2026-10-26 09:00 B027 局党组会 谷六
```

### 能识别的日期写法

| 写法 | 例子 |
|---|---|
| 中文 | `10月31日`、`10月31号`、`2026年10月31日` |
| 短横 / 斜杠 | `10-31`、`10/31`、`2026-10-31` |
| 点号 | `10.31`、`2026.10.31`、`11.5号` |
| 空格 | `10 31`、`2026 10 31` |
| 星期 | `星期四`、`下周三` |

这些**不会被误判成日期**：`14:30`（时间）、`3.5米`（小数）、`5楼3号`（楼层）。

### 修改 / 删除一场会议

- **改**：在日历上点那张会议卡片 → 弹窗里改 → 保存。新内容会自动写进云文档，旧登记同时撤下，不会出现两条。
- **删**：卡片上删除后，云文档的删除**默认不自动执行**（删错不可撤销）。需要到「⬆ 同步云文档」里确认后才会同步删除。

### 复制报送名单

点右下角「📊 参会统计」悬浮卡，底部有：
- **复制本周参会名单**：生成可直接粘贴的整周名单（未指定领导写「待定（建议：X）」）
- **只复制参会领导**：只列人名

## 五、界面与分屏使用

### 布局（宽屏）

```
┌─────────────────────────────────────────────────┐
│  顶栏：标题 · 周切换 · 同步/读回 · 更多▾          │
├──────────────┬──────────────────────────────────┤
│ 录入区       │  本周日历（7 列，按领导分列）       │
│ （粘贴/解析） │  周一 … 周日，上午/下午两个时段     │
└──────────────┴──────────────────────────────────┘
```

### 分屏 / 窄窗口（窗口宽度 ≤ 1180px）

本应用**专门为分屏做了响应式适配**。把窗口拖窄后：

1. **录入区自动收进抽屉**：左侧不再常驻，日历占满整个窗口。
2. 点顶栏 **「＋ 录入」** 按钮 → 录入区从左侧滑出，录入完自动收回；点遮罩、右上角 ✕ 或按 Esc 也能收起。
3. **日历自动折行**，随窗口宽度逐级调整：

| 窗口宽度 | 日历列数 |
|---|---|
| 很宽（>1280px） | 7 列（一周并排） |
| 1280 ~ 1180px | 6 列 |
| 1180 ~ 960px | 5 列 |
| 960 ~ 720px | 4 列 |
| 720 ~ 500px | 2 列 |
| < 500px（手机） | 1 列 |

4. 顶栏次要按钮（参会统计、外出培训、文件监听、分工规则、数据管理、主题切换）收进 **「更多 ▾」** 下拉菜单，统一 4 字命名，顶栏只留最常用的。

> 无论窗口怎么缩，日历都能完整显示、卡片文字不会被裁掉。分屏使用时，建议把窗口拉到「日历 4~5 列」的宽度，最舒服。

## 六、同步到云文档

### 实时同步（默认开启，无需操心）

| 能力 | 说明 |
|---|---|
| 自动写入 | 日历新增/修改，约 1.5 秒写进云文档；已存在的自动跳过，不重复 |
| 改了也会同步 | 改时间、改地点都算修改：云文档里那一场会被**换成新内容**，不会新旧两条并存 |
| 自动读取 | 每 30 秒检查云文档，有变化才读回日历，没变完全不打扰 |
| 自动删除 | 日历删会议时同步删云文档——**默认关闭**，需手动确认 |

卡片右上角的小角标能看出同步状态：

| 角标 | 含义 |
|---|---|
| `✓` 绿 | 云文档里已经是这个版本 |
| `⟳` 黄 | 云文档里还是旧版本（刚改了时间或地点），正在/等待写回 |
| `!` 红 | 云文档里这场已经被删了，下次检查后从日历移除 |
| 无 | 还没写过云文档（等自动同步，或点「⬆ 同步云文档」） |

### 什么时候需要手动操作

- **云文档那边有人直接改了**，想立刻看到：点顶栏「⟲ 读回云文档」
- **删了会议想让云文档也删**：点「⬆ 同步云文档」→ 在「需同步撤下」区块确认
- **想完全停止自动同步**：点右上角「● 实时同步中」→ 关掉「开启实时同步」开关

### 云文档里删掉的会议，日历也跟着删

在金山文档里手工删掉一条登记后：

1. 日历对应卡片右上角先变成红色 `!`（提示「云文档里已删除，下次检查后移除」）
2. 下一次检查（约 30 秒）确认后，自动从日历移除
3. 记入同步面板「云文档里删掉了 N 场会」，随时可「全部恢复到日历」

**保护机制**（避免误删）：

| 情况 | 行为 |
|---|---|
| 整张表读成空的（接口异常/文档被清空） | 一场都不删 |
| 领导列被删掉或改名 | 判不出，不动 |
| 从没写进云文档的本地会议 | 不动 |
| 一次少了 9 场以上 | 先不删，列出清单等你确认 |
| 手动点「⟲ 读回」 | 视为你亲自确认，一次就删 |

### 手机 / 别的电脑打开，看到的和这台一致

冲突提示里点过「连开/衔接」「判为冲突」「忽视」，以及登记的外出培训，都会跟着云文档走：

- 这些内容存在云文档里另开的一张 **「应用状态」** 表里，**《会议安排》主表一个字符都不动**
- 换设备（手机、同事电脑）打开，**不会再问你一遍已经裁决过的冲突**
- 那张表是程序自动维护的，**别手工删**（删了手机端会重新提示冲突）；表里第四列写了这句话

### 服务改了代码要重启

`更多 ▾ → ⟳ 重启服务` → 页面自动刷新，登录凭证不用重填。
（提示「服务是旧版本」时也点这里；万一这个旧服务连重启都不认，重启一次电脑即可。）

## 七、参会统计与外出培训

### 参会统计（右下角悬浮卡）

- **周 / 月**切换：两边都能左右翻
  - 周口径：默认跟随日历当前周，点「‹ ›」前后翻周，中间显示那一周的日期区间（如 `10.19—10.25`），标题会从「本周」变成「该周」
  - 月口径：默认跟随日历当前月，点「‹ ›」前后翻月，中间显示年月
  - 点中间那段文字 = 回到当前这一周 / 这一月（恢复跟随日历）；翻统计周期只动统计卡，不动左边日历
- 按场次排名，点某位领导可看他的逐场明细（日期/时间/会议/地点），可复制
- **已调出的领导**（如姜九）：只有该周期里确实有他调出前的会议时，才在底部单列一句「调出前 N 场已计入」；调出之后的周/月一场都没有，就不再出现任何与他有关的字样（过去周期里的记录照旧保留）
- 底部一键复制本周（本月，或翻到的那一周/月）参会名单

### 领导外出培训（「更多 ▾ → 🎓 外出培训」）

- 登记领导、起止日期、培训名称、地点
- 培训期间日历上显示紫色虚线占位，点它可编辑
- 培训期间还给他排了会，卡片会红字提示冲突
- 支持导出 CSV，复制名单时单独列【外出培训】段
- 云文档里只标了首末两天「外出培训」也能认：同一领导、同一培训名称的多处标记会**并成一段连续培训**（相邻标记隔得远则仍算两段），不会再读成「只培训了那两天」
- 自己改过/删掉的培训以你的为准：云文档里那几处标记不会把区间重新撑回去，也不会让删掉的培训复活

## 七之二、文件监听（自动发现会议通知）

> 「更多 ▾ → 📁 文件监听」

指定一个文件夹，之后往里放 **Word / PDF / 图片** 的会议通知，应用会自动解析，并在**右下角弹提醒**问你「要不要导入日历」。

### 怎么用

1. 点「📁 文件监听」→ 勾选「开启文件监听」
2. 填文件夹路径：可以直接粘贴，也可以点下面的**常用位置**（桌面/下载/文档/盘符），或逐级点选子文件夹
3. 点「检查」确认路径可用（会显示能解析几个文件）
4. 点「保存设置」

### 右下角提醒长什么样

- 卡片显示：**文件名 + 识别出的日期时间 + 地点 + 会议名**
- 三个按钮：
  - **导入到日历** — 直接入库（已存在的同场会议会自动跳过，不会重复）
  - **查看原文** — 看提取到的完整文字，也能在弹窗里直接导入
  - **忽略** — 以后不再提醒这个文件
- 右上角 ✕ 只是「这次先不看」，文件仍留在待办里，下次进应用还会提醒（可在设置面板「在右下角显示」找回来）
- 一次放进去多个文件，卡片会依次堆叠；「更多 ▾」按钮上有待办数量角标

### 几条要知道的规则

- **首次开启不轰炸**：开启那一刻，文件夹里已有的文件当作「已存在」，不提醒；之后新放进去的才提醒
- **等文件复制完再解析**：拖进去的文件要经过连续两次扫描确认大小稳定，才动手解析（一般 3～6 秒），避免读到半个文件
- **不重复提醒**：同一个文件处理过（导入或忽略）就不再问；同名文件内容变了会重新提醒
- **失败也会说**：解析不出来（比如加密 PDF、模糊扫描件）同样会弹卡片，并写明原因，可以点「查看原文」看提取结果
- **只在服务开着时生效**：同步服务（`启动同步服务.bat`）没起来时，监听功能会显示离线提示

### 隐私

全程**本机完成**：文件夹在本机、文字提取用本机 Python（`extract_file.py`），**不联网、不上传**。配置和待办记录存在 `bridge/.watch-config.json`、`.watch-pending.json`、`.watch-seen.json`，都是本地文件。

## 八、开机自启与启停管理

同步服务已设为**开机自启 + 崩溃自动重启**，正常情况下**什么都不用管**。

**开机自启不会弹黑窗口**：服务由计划任务经 `run-daemon.vbs` 在完全隐藏的环境里启动，桌面上和任务栏里都看不到 CMD 窗口。（只有手动双击 `启动同步服务.bat` 才会有窗口——那是为了让你看到启动日志。）

在应用文件夹（`会议日程应用/`）里，有 4 个脚本：

| 脚本 | 作用 | 什么时候用 |
|---|---|---|
| `查看运行状态.bat` | 看服务是否在线、计划任务状态、上次运行时间 | 怀疑服务没跑时 |
| `停止同步服务.bat` | 停止服务 + 取消开机自启 | 临时不想让它跑（如系统维护） |
| `恢复自启动.bat` | 恢复开机自启 + 立即启动 | 停止后想恢复 |
| `启动同步服务.bat` | 手动启动一次（旧方式，一般不直接用） | 特殊排查时 |

**停止后如何恢复**：双击 `恢复自启动.bat` 即可。

> 注意：`停止同步服务.bat` 是**手动停止**的唯一入口。平时它自己不会停；即使进程崩溃、被杀，也会在几秒到 1 分钟内自动拉起。

## 九、注意事项

1. **页面开着才实时同步**。关掉网页，自动同步暂停；下次打开会自动补上（先读回、再补写），不会丢数据。
2. **云文档是「追加写」**。写错了只能手动去金山文档里删，程序不会自动覆盖。所以每次大量导入前，先核对预览。
3. **删会议要谨慎**。日历删会议 ≠ 云文档立即删，需在同步面板确认；一旦确认删除，云文档那条就没了。
4. **登录凭证别外传**。凭证在 `bridge/.auth.json`，请勿复制给别人。
5. **改了代码要重启服务**。如果（由技术人员）改了 `bridge/*.mjs`，需运行 `停止同步服务.bat` 再 `恢复自启动.bat` 让新代码生效。
6. **数据主要存两处**：浏览器 localStorage（日历）+ 金山文档（留档）。云文档是权威备份，最坏情况可用「读回」重建日历。

## 十、常见问题与解决建议

### Q1：打开页面显示「检测同步服务」/「同步服务未启动」

**原因**：后台同步服务没在运行（可能被手动停过，或开机后还没起来）。

**解决**：
1. 双击 `查看运行状态.bat`，看「服务状态」是不是「离线」
2. 双击 `恢复自启动.bat`，等几秒
3. 刷新页面（Ctrl+F5）

### Q2：页面提示「未知接口」或「旧版本，请重启」

**原因**：后台跑的是旧代码（改了 `bridge/*.mjs` 没重启）。

**解决**：双击 `停止同步服务.bat` → 再双击 `恢复自启动.bat` → 刷新页面。

### Q3：右上角是黄点，不是绿点

**原因**：服务在线，但还没授权登录金山文档。

**解决**：点黄点按钮 → 在弹出页面点「同意」→ 变绿点即完成。

### Q4：登录过期了怎么办

**原因**：金山文档授权有有效期。

**解决**：右上角会出现「重新登录」提示，点一下重新授权即可（不用重新输账号密码，除非换了账号）。

### Q5：解析出来的日期/时间/领导不对

**原因**：会议原文表述有歧义（如「下午」没写具体几点、「崔局」简称）。

**解决**：**在预览卡片里直接改**再导入。不要直接导入错的。常见可纠正的：
- 时间写了「下午」没写几点 → 预览里补上
- 领导用简称（如「崔局」）→ 预览里选准全名

### Q6：同一场会议在云文档里出现了两条

**原因**：可能手写进过云文档，又从日历导了一次，且判定没认出来。

**解决**：去金山文档里手动删掉重复的那一条。程序后续会自动读回，日历侧不会因此再重复。

### Q6.5：改了会议的时间和地点，云文档没跟着变

**原因**：旧版本只按「会议名称 + 开始时间」判断云文档里有没有这场会，改过之后认不出来，就当成「已经有了」跳过了。

**解决**：现已修复。点开会卡片改完并保存后：

- 卡片角标会从 `✓` 变成 `⟳`，约 1.5 秒后自动把云文档里那一场**替换**成新内容（不会多出一条）
- 如果角标一直是 `⟳` 不动，点「⬆ 同步云文档」，在「待写入」表里能看到标着 **更新** 的那一条
- 万一云文档里那条被人手工删过，程序出于保护不会自动写回；在同步面板点「仍然写回」即可

### Q6.6：拖进来的 Word / PDF 提示「解析失败」

**原因**：旧版本靠本机 Python 的 python-docx / pypdf 解析，程序环境一升级，这两个包会被清掉，于是报 `No module named 'docx'`。

**解决**：现已改为程序自己解析，**不再依赖 Python**（只有图片识字还用 Python）。

- 拖进来直接能出文字，Word 里的表格也会按「行 / 列」保留
- 文件夹提醒的卡片如果还挂着失败状态，点卡片上的 **「重试解析」** 就行，**不用把文件再放一遍**
- `.doc`（Word 97-2003 老格式）现在**直接解析**，不用再转成 `.docx`；`.ofd`（版式文件）程序仍读不了，会提示你「另存为 .docx」
- `.wps` / `.xls` / `.ppt` / `.rtf` 等也读不了，会提示你转成 `.docx` 或 `.pdf` 再拖进来
- 扫描件 PDF（整页是图片）取不到文字，会明确告诉你「这是扫描件」，改用截图粘贴识别
- 旧版 `.doc` 以前会被误送 OCR、弹出「本机缺少解析组件」的内部报错，现已改为本地解析（走 `word-extractor`）；若提示「缺少 .doc 解析组件」，在「会议日程应用」目录执行 `npm install word-extractor` 即可

### Q7：删了云文档的会议，日历里那场还带着 ☁ 或红色 `!`

**原因**：删除需要两次检查确认（默认 30 秒一次），还没到第二次。

**解决**：等 30~60 秒自动移除；或点「⟲ 读回云文档」立即处理。

### Q8：电脑重启后服务没起来

**原因**：极少数情况计划任务没触发。

**解决**：双击 `恢复自启动.bat`。若反复出现，双击 `查看运行状态.bat` 看「上次结果」的错误码，把截图发给我排查。

### Q9：想彻底停用一段时间

**解决**：双击 `停止同步服务.bat`。它会停止服务、取消开机自启。想恢复时双击 `恢复自启动.bat`。

### Q10：换电脑 / 换浏览器后日历空了

**原因**：日历数据存在原浏览器的 localStorage，没跟过来。

**解决**：
- 云文档数据还在 → 新电脑打开应用，点「⟲ 读回云文档」或等自动读回，即可重建日历
- 若之前导出过 JSON → 用「更多 ▾ → ⇅ 数据管理 → 导入 JSON」恢复
- 建议平时定期「导出 JSON」备份

### Q11：局域网其他电脑打不开 / 一直转圈

**原因**：通常是主机未开机、服务未启动、IP 变了，或防火墙拦截。

**排查**（按顺序）：
1. **主机是否开机**、服务是否在线——在主机上双击「查看运行状态.bat」确认「服务状态：在线」
2. **IP 是否变了**——主机上运行 `ipconfig` 看当前 IPv4 地址；若不再是 `192.168.1.100`，让同事用新地址访问。**建议在路由器里绑定固定 IP**，一劳永逸
3. **防火墙**——确认主机防火墙入站规则「会议日程-局域网访问(7788)」处于「允许」状态
4. **是否同一局域网**——必须连单位的同一 WiFi/网线，手机流量热点连不进来

### Q12：忘了访问口令 / 想改口令

**改法**：在主机上打开 `会议日程应用\bridge\.access-key.txt`，把内容改成新口令，保存后双击「恢复自启动.bat」重启服务即生效。

**忘了就重新设一个**（口令是明文存储的，直接看该文件也能找回）。
